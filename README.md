# ActionShortsMaker

Automated 9:16 action Shorts from videos you own or have permission to edit.

On Windows, double-click `setup_windows.bat` once, then `run_demo.bat` to render the demo or `run_ui.bat` to open the studio. Windows downloads go into `downloads/`; outputs go into `outputs/`. Python 3.11 and FFmpeg are installed with winget when absent.

On Ubuntu/Debian with `sudo` and internet access:

```bash
cd action_shorts_maker
bash setup.sh
./venv/bin/python main.py --test-demo
./venv/bin/python app.py
```

`setup.sh` checks and installs FFmpeg, Python venv/pip, a bold DejaVu font, and OpenCV system libraries, installs Python requirements in `venv`, downloads `models/yolov8n.pt`, and downloads the McQueen test video into `inputs/`. The demo can be large. YouTube may require sign-in or block automated downloads in some regions; if that happens, supply a local, authorized video instead.

Other CLI examples:

```bash
./venv/bin/python main.py /path/to/video.mp4 --count 3 --length 16 --preset comic
./venv/bin/python main.py /path/to/video.mp4 --start 45 --length 12 --caption 'WATCH OUT!'
./venv/bin/python main.py 'https://www.youtube.com/watch?v=-brcT3E5Dcg' --count 1
```

Outputs default to MP4 (1080×1920 at 60 fps, H.264/AAC) in `outputs/`; the studio also offers a 720×1280 at 30 fps fast-preview mode. Automatic clips run approximately 16–20 seconds around a verified collision and end about 4.5 seconds afterward. For sources over 90 seconds the automatic selector excludes footage before 22 seconds and within the last 15 seconds. It combines high-passed (>1.5 kHz) percussive audio flux with 320×180/5fps motion-change spikes and low-resolution YOLO vehicle evidence before selecting a crash; if none are verified it errors rather than choosing intro music or B-roll. Manual start and duration controls remain available. The cropper tracks vehicles with YOLO and uses motion when no vehicle is detected. Presets add optional event-timed shake, zoom, comic captions, and normalized audio. The Gradio studio lets you select a suggestion or edit the start time, choose a preset and caption, preview, and download the finished file.

For a single-clip benchmark, run `venv\Scripts\python.exe main.py --test-demo --max-clips 1` on Windows. The command prints tracking time, render time and total time including analysis. The optimized renderer samples 640×360 tracking frames at 10 fps, interpolates and smooths the resulting crop trajectory, rasterizes overlays once, and passes timed crop and overlay instructions to a single FFmpeg filter/encode/audio-mux process (no Python frame pipe or intermediate MP4). FFmpeg-native crop/scale was measured faster than piping every Full HD frame through Python on this machine. It uses `h264_nvenc` only if a real hardware encode probe succeeds; otherwise it uses `libx264` on CPU. Real-world render time depends strongly on the GPU, CPU, disk and source codec.

Twelve kids/cartoon effects are synthesized automatically in `assets/sfx/` at 44.1 kHz: slide whistle, countdown, police siren, train horn, scurry, spring boing, skid, riser, boom, bonk, clown honk, and descending trombone. The default Hyper-Fun mode schedules up to 11 cues per clip (including two simultaneous impact layers); Ultra-Dense schedules 17 recorded cues, Standard uses four, and Off disables them. The original audio is EQ-softened and played at 28% by default (`--orig-volume 0.28`, range 0–1). `amix=normalize=0`, limiting, and loudness normalization are performed inside FFmpeg's single-pass render. Use `--sfx-density ultra|hyper|standard|off`, `--no-sfx`, or `--sfx-intensity 0.6` (range 0–1.5). Place an `.mp3`/`.wav` in `assets/sfx/` and select it with `--impact-sfx filename.mp3` to replace the boom; the Gradio studio has matching controls. Only use custom audio you are licensed to use.

The default sound style is now `--meme-style real`, playing short recorded meme sounds from `assets/sfx/real_memes/`; `--meme-style hybrid` adds a few cartoon accents and `--meme-style synthetic` uses only the generated pack. Run `venv\Scripts\python.exe main.py --fetch-memes` (or `core\meme_fetcher.py`) to download/refresh the 28 clips. The downloader searches labeled Myinstants MP3s first, optionally falls back to short YouTube search results and Edge TTS for vocal lines, then trims and normalizes stereo 44.1 kHz WAVs. `assets/sfx/real_memes/sources.json` records the source URL or TTS origin, duration and peak for each sound. A missing pack does not cause a network request on every render; synthetic cues are used where individual recordings are unavailable. The studio includes pack refresh, individual preview and upload controls; uploaded extras can be selected as a custom impact. **Downloaded meme recordings may be copyrighted. Verify usage rights before publishing.**

### MCP studio pipeline (i5-14400F / 16 GB / RTX 3070)

Install with `venv\Scripts\python.exe -m pip install -r requirements.txt`. The project `opencode.json` registers `action_shorts_maker` as a local stdio MCP server; configure the same `mcp.servers.action_shorts_maker` command globally to use it outside this directory. Its tools are `process_youtube_links(urls, mode="short", max_clips=1, background=True)`, `get_job_status(job_id=None)`, `analyze_video_storyboard(url)` and `list_completed_projects()`. Background calls return a job ID immediately and append steps to `outputs/live_status.log`; use `get_job_status` for results. Jobs remain active while the MCP server process is alive. Set `mode="both"` for both videos or `background=False` to wait for completion (which may exceed UI timeouts). A single URL or list is accepted. Each URL gets a Windows-safe title folder in `outputs/` containing the requested 18s/57s 60fps MP4s, 1080×1920 and 1280×720 covers, US SEO, a JSON manifest with actual frame counts/loudness, a six-frame contact sheet for each candidate, and an expert EDL report. The title sanitizer handles reserved Windows device names. The source is cached in `downloads/` and the renderer streams low-resolution samples instead of accumulating decoded source video. At most two heavy jobs run together, with six FFmpeg threads per process or NVENC. AI failures are labeled `local-fallback`, not presented as live expert advice. Third-party Myinstants audio has separate publishing rights.

The 40-item pack is populated by `venv\Scripts\python.exe -m core.meme_fetcher`; the extra 12 sounds are downloaded from Myinstants with individual provenance in `assets/sfx/real_memes/sources.json`. The 20Hz physics/audio scan anchors seven sub-events; output motion is interpolated from a 31-sample Savitzky–Golay-smoothed tracking trajectory into FFmpeg crop expressions evaluated each frame. It uses a damped impact pulse, saturation/contrast/sharpness, a bottom progress bar and clean action-window dividers, with CFR 60fps output. Use `venv\Scripts\python.exe verify_demo.py` to verify the organized demo and frame PTS spacing.

### English AI director, thumbnails and SEO

Set `AI_API_BASE=https://php-tool-shop.proxy-api.shop/`, `CODEX_API_KEY` (or legacy `AI_API_KEY`), `AI_MODEL=gpt-5.6-sol`, and `AI_MARKET_LOCALE=en-US` in the project-local `.env` (ignored by Git). The director sends the exact `{model, input}` payload to `POST <AI_API_BASE>/responses`, trying a small JPEG first and falling back to plain-string crash telemetry if vision fails. `gpt-5.6-sol`, `gpt-6-sol`, and `gpt-6-luna` are selectable through `--ai-model` or the studio. Each automatic selection writes a 1080×1920 vertical and 1280×720 horizontal crash thumbnail (`*_thumb_vertical.jpg`, `*_thumb_horizontal.jpg`), English upload metadata (`*.metadata.json`) and a copy-ready `*_seo_us.txt` with title, description and tags. Director captions and recorded sound choices are applied during rendering. Use `--ai-assets-only` to regenerate assets without re-encoding video, or `--no-ai-director` for deterministic English metadata. `director_mode` is `live-ai` only after a successful API response; otherwise it is `local-fallback`.

`--shorts-mode viral` keeps single crashes under 25 seconds. `--shorts-mode classic59` compiles three ~19-second non-overlapping crashes into a ~57-second Short with a hard 59-second maximum. `--shorts-mode extended179` can compile up to nine clips under 179 seconds. Use `--max-clips` or `--desired-duration` to adjust the compilation. The compiled file is saved as `outputs/<source>_classic59_compilation.mp4` or `outputs/<source>_extended179_compilation.mp4`. The UI has matching duration mode, compilation, SFX and volume controls.

The default camera framing uses `--fov-scale 1.75`: on a 1920×1080 source the tracked full-height crop is 1064 pixels wide instead of the legacy 608 pixels. The aspect-preserving 1080×1096 action foreground is centered on a blurred action backdrop within the 1080×1920 square-pixel canvas (SAR 1:1). Captions stay in the upper blurred bar. Use `--fov-scale 1.0` for the old tight fullscreen crop, or adjust from 1.0 to 2.5 (for example `--fov-scale 2.2`). The UI offers Wide Balanced, Medium, Ultra-Wide, and Tight presets plus a custom FOV slider; choosing a preset sets the slider, which controls the effective width. Multi-object tracking blends the primary vehicle and nearby vehicles/trains; at impact both crop dimensions shrink together for a distortion-free 1.04× zoom. Automatically selected single clips end within 4.5 seconds after the crash and target 16–20 seconds total.

NVIDIA CUDA is used when the installed PyTorch build and drivers support it; otherwise inference runs on CPU. For a specific CUDA runtime, install the compatible PyTorch build in the venv using the official PyTorch selector before running the app. The first run downloads model weights and may take longer. This project does not guarantee that a particular YouTube upload remains accessible or licensed for reuse.
